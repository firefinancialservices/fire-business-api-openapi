> 📘 HTTP response codes indicate whether a specific HTTP request has been successfully completed

<br />

Fire do not reveal all our error codes for security reasons. Error codes can be identified in a few different ways, and are useful for identifying why a call to the Fire Payments API has failed. The codes should give you some guidance as to what has gone wrong, but this guide will provide a thorough explanation of these codes, and potential next steps.

***

## Response code types

Response codes are grouped by their starting digit, as shown below. You can identify the type of code for any response like this, no matter the numbers that follow.

![](https://files.readme.io/044bc7347930e3f0d2ccba4fbe766a8938aaa18d78a8a4f4a784891792b2b928-image.png)

Any successful Fire Payments API call will have a 200 response.
