title: Add an international transfer to a Batch
excerpt: >-
  This endpoint allows you to add an international transfer to a batch.
  International transfers must be added to a batch using the Payee ID (**Mode
  1**). Payees must be set up using the web application.


  **Mode 1:** Use the payee IDs of existing approved payees set up against your
  account. These batches can be approved in the normal manner.
